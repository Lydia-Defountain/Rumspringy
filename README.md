# Rumspringy
This is a small game where you play Rummy against a CPU opponent. Play with a normal deck or with the alternate deck which has different suits and new ranks to deal with!

Earn points by both setting groups of same rank or a straight of 3 or more or by adding to an existing set! Higher the rank of card (Including the value on the Jokers) the higher the score!

lose points by having cards of left in your hand when the deck runs out or you or the CPU runs out of cards. The higher the rank the more points lost!

But those high rank cards do mean more points. Balance if you hold onto something good to set down or try to run lower.


Hackathon for boot.dev project

# Running
This project uses `uv` to handle its dependencies. To run:

- install uv if needed: `pip install --user uv`
- run via uv: `python -m uv run main.py`
